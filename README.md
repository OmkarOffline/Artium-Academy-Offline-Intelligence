# Artium Academy Offline Intelligence

One page that brings together Artium's offline-centre tools:

| Tab | File | What it is |
|---|---|---|
| Offline Centres | `dfd.html` | Offline business DFD: functions, initiatives and progress. Editable in the page, and saves back to this repo. |
| Lead to Purchase | `dashboard.html` | Alwarpet, Chennai centre dashboard. Reads live data from the published Google Sheet. |

`index.html` is the top bar and tab switcher. You can link straight to a tab with `#centres` or `#dashboard`.

## Saving edits on the Offline Centres tab
The first time you save, the page asks for GitHub settings. Enter:
- Username: `omkaroffline`
- Repository: `Artium-Academy-Offline-Intelligence`
- File name: `dfd.html`
- A personal access token that can write to this repo

Combined from `lead-to-purchase-dashboard` and `offline-business-dfd`. Those repos are left unchanged.
